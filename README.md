# Solvian — Help & Support

This repository hosts the Help & Support web resources for **Solvian**, developed under **[MRIS LLC](https://github.com/mrisllc)** (**MRIS Technologies Co LIMITED**).

## Overview
- **Project:** Solvian Help & Support
- **Organization:** [MRIS LLC](https://github.com/mrisllc)
- **Repository:** `Solvian-help-support-`
- **Purpose:** Support documentation, FAQs, issue reporting guidance, and web pages for Solvian users.

## Sections & Pages
- **Help Center:** General guidance and support information for Solvian.
- **FAQ:** Answers to common questions.
- **Report a Problem:** Support ticket / problem reporting interface routed to `contact.mrisllc@gmail.com`.

## Notes
- Support ticket IDs generated on the web form (such as `#TKT-...`) help track reported issues alongside email follow-ups.
- Browser-reported device details on web forms may be limited due to modern browser user-agent privacy handling, so clear steps to reproduce are helpful when reporting issues.
